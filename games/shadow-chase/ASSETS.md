# Shadow Chase — asset provenance

Canonical art direction: **Toy**. The runtime is a tactile wooden shadow
theatre built from opaque raster stage plates and transparent raster props.
HTML/CSS supplies layout, hit areas, transforms, accessibility, and state only;
there are no SVG, emoji, canvas, gradient, or CSS-drawn primary illustrations.

All model calls happened during authoring. The shipped game makes no runtime
model or off-origin media request. Original generations and runtime derivatives
are released with QLOBE Kids under CC BY 4.0; code is MIT.

## Layering, rejection, and deterministic finalization

`tools/generate-layered.py` calls the approved LAN `qwen-image-layered`
workflow asynchronously and selects `layer_2`. Seed-42 extraction was accepted
for the toys, exact title, and sun track; their recipe files record source,
prompt, output, alpha statistics, and workflow.

The whole-sheet Qwen UI result was retained as
`assets/source/layered/ui.png` with a `needs-human-review` receipt, but it was
rejected for production because three of the six required props were omitted.
Individual Qwen retries were empty or unreliable. The accepted fallback first
made immutable per-cell sources, then removed the known uniform charcoal matte
with a soft color-distance alpha ramp. Each UI receipt truthfully records
`workflow: deterministic-charcoal-matte`; it is not mislabeled as a model
result. The star uses a tighter 15/22 cutoff/feather pair to preserve its carved
dark rim without a black halo.

`tools/finalize-art.py` is the reproducible shipping pass. It:

- retains only the largest connected alpha component for each animal;
- runs the repository cutout finalizer at 640 px with a 12 px pad;
- derives each silhouette from the corresponding accepted toy alpha;
- creates the three full-raster stage lighting states;
- warms and resizes the project-owned pause control;
- writes WebP shipping files, saturated-magenta cutout reviews, a theatre
  composite, and `assets/source/art-qa.json`.

The current report has zero failures. Fifteen foreground assets pass their
alpha review, and all four stage plates remain under the 350 KB budget. Human
review evidence is retained in
`assets/source/qa-magenta-contact-sheet.png` and
`assets/source/stage-composite-review.png`.

## Narration and audio QA

`tools/generate-voice.py` batches all candidates through the approved local
Qwen3 voice-clone workflow before batching Whisper analysis, avoiding model
thrash. It uses the rights-cleared canonical teacher reference and deliberately
keeps host URLs and private reference paths out of committed receipts.

`assets/audio/lines.json` and `config.json` contain the same 25 lines.
`assets/audio/manifest.json` records file, decoded duration, text hash, and seed;
`assets/audio/qa.json` records the expected text, heard transcript, similarity,
model, threshold, attempts, and accepted state. Per-line recipes record the
same evidence. Every shipped line is seed 7 and passed Whisper `base/en` at
1.0 normalized transcript similarity; the corrected noon line also passed 1.0
token similarity. An older ambiguous “Noon sun…” take and its retry are retained
under `assets/source/voice-raw/` as rejected provenance and are never selected
by the runtime audio manifest. Like the other authoring sources, these files are
deliberately deployed under the game's static `assets/source/` tree and covered
by the project CC BY 4.0 asset license; the private voice reference itself is
not copied there.

The 25 shipping clips total 929,278 bytes. Decoded durations range from 1.677
to 4.700 seconds; measured means range from −19.5 to −18.3 dB and peaks from
−4.8 to −0.6 dB. Device speech remains an accessibility fallback only.

## Rebuild and review

- `python3 games/shadow-chase/tools/generate-layered.py --dry-run`
- `python3 games/shadow-chase/tools/finalize-art.py --force`
- `python3 games/shadow-chase/tools/generate-voice.py --dry-run`
- `node tools/pipeline/capture_og_images.mjs --only shadow-chase --force --base http://127.0.0.1:8000`
- `node games/shadow-chase/tools/qa.mjs --base http://127.0.0.1:8000 --shots /private/tmp/qlobe-shadow-chase-shots`

Reject a rebuild if any toy identity or title spelling drifts, a contact-sheet
neighbor survives a crop, a transparent edge shows a dark aura on saturated
magenta, the three time cards do not show distinct shadow length/direction, or
any primary visual falls back to CSS/vector/emoji art.
