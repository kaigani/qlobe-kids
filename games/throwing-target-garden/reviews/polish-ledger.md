# Throwing Target Garden — production and polish ledger

This ledger records completed production passes, not wall-clock time. It is a
conservative work-unit proxy for the requirement that at least half of the
effort follow the first functional build and focus on visual, interaction, and
gameplay polish. Blocked or production-only work is listed separately and is
not counted as completed.
