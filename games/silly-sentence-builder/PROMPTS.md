# Silly Sentence Builder — Production Prompts

All runtime art is original project art generated with the built-in image
generation workflow at the user's explicit request for GPT Image 2. Accepted
masters are committed under `assets/source/gpt-image-2/`; runtime derivatives
are deterministic crops and WebP encodes.

## Shared art direction

Premium handcrafted quiet-book puppet theater made from wool felt, fleece,
padded appliqué, embroidery, blanket stitching, visible fibers, soft stuffing,
and warm upper-left theatrical light. Palette: midnight navy, dark plum, teal,
warm cream, mustard, coral, lavender. No plastic, clay, paper, vector look,
watermark, or functional generated text.

## Master prompts

- **Theater:** 4:3 straight-on empty navy felt stage, plum curtains and mustard
  rope, teal scalloped footlights, calm central 70%, no character or UI.
- **Title:** plum padded plaque with cream appliqué letters spelling exactly
  `SILLY / SENTENCE / BUILDER`; background-extraction edit changed only the
  outside matte to alpha.
- **Characters:** 3×2 alpha sheet: orange cat, purple dinosaur, teal fabric
  robot, yellow duck, coral-pink bunny, sky-blue one-horned monster.
- **Places:** 3×2 alpha sheet: moon, bubbly bathtub, rainbow castle, cupcake
  picnic, flower garden, purple pirate ship; each has a puppet landing area.
- **Actions:** 3×2 alpha sheet: dancing notes/feet, trumpet, juggled pancakes,
  pogo stick, tiny rocket, brush with rainbow swoosh.
- **Manners:** 3×2 alpha sheet: snail, backward footprints, jelly blob, hopping
  feet, spiral loop, tutu.
- **UI:** 4×3 alpha sheet: sentence strip; four pockets; four cream card faces;
  plum action plaque; gold star; cream/plum label plaque. All blank.
- **Krea hub tile:** single centered felt puppet-theater tableau with the cat,
  dinosaur, and robot peeking from three colored story pockets around a blank
  cream sentence strip; 6:5, no text or UI chrome.
