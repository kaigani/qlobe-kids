All primary visible art is raster Claymation media. Functional words and labels remain live HTML over the authored clay surfaces. No vector, SVG, emoji, CSS gradient, or runtime-generated artwork is used.

## Production decisions

- GPT Image 2 established the coordinated world and exact contact-sheet geometry; independent per-object generations were avoided to prevent material and lighting drift.
- Qwen Image Layered was used only for separation. `layer_2` is preferred, but both returned layer roles are inspected because the service can swap them for a blank plaque. Only an output with meaningful transparent and visible pixels may proceed to deterministic trim/pad/encode; empty, opaque, or identity-damaging output is preserved as rejected evidence and retried with seeds `42 → 1337 → 9001 → 7`. Full-size contact review corrected source boxes for wide/tall subjects and retained deterministic separation for the seven objects where it was visibly superior.
- Runtime scene cards remain opaque square photographs because they are composed behind an authored clay frame; they are not cutouts.
- The 12 scene panels use full-size-inspected source bounds rather than equal grid cells. This removes the charcoal master-sheet gutters at the source and keeps the cream/grape runtime frame aperture clean without CSS masking.
- The corrected fox/bug source is a GPT Image 2 precise edit. No additional Qwen Image Edit was shipped because there was no bounded repair that improved the accepted masters without risking identity drift.
- MiniMax H3 video was evaluated and omitted: the core learning action is direct manipulation, and a passive vignette would add weight without clarifying decoding or comprehension. Stop-motion motion is applied to raster assets in runtime instead.
- Generated lettering is never used for functional sentence content. The one generated title lockup was accepted only after exact spelling review.

## Reproduction

From the repository root:

```sh
python3 games/tiny-sentence-workshop/tools/build-media.py --deterministic
QLOBE_QWEN_URL=<configured-LAN-endpoint> \
  python3 games/tiny-sentence-workshop/tools/build-media.py --layered
python3 games/tiny-sentence-workshop/tools/build-media.py --qa-contact
QLOBE_QWEN_URL=<configured-LAN-endpoint> \
  python3 games/tiny-sentence-workshop/tools/build-media.py --hub --seed 42
QLOBE_QWEN_URL=<configured-LAN-endpoint> \
  python3 games/tiny-sentence-workshop/tools/generate-voice.py \
    --voice-ref shared/assets/refs/voice-teacher.wav --workers 2
python3 games/tiny-sentence-workshop/tools/generate-voice.py --check
node tools/pipeline/capture_og_images.mjs \
  --base http://127.0.0.1:8000 --only tiny-sentence-workshop --force
```

The LAN endpoint, local job IDs, and private reference path are never committed. Only regeneration parameters, accepted seed, media hashes, and the teacher-reference checksum are retained.

## Acceptance gates

- Scene identities, action/spatial relation, paired-character consistency, light direction, and clay material all read correctly at runtime scale.
- Every Layered UI final has real alpha, no charcoal box, no halo or debris on saturated magenta, and stable padding/aspect.
- The title is spelled exactly once; no functional generated text appears elsewhere.
- Hub artwork contains no letters, logos, or ambiguous focal objects and remains legible at 320px wide.
- Every shipped voice clip matches its exact line by Whisper, passes duration/volume/clipping and checksum checks, and remains subject to the child iPad listening/playtest before promotion from beta.
