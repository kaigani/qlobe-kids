# Animal Motion Cards — image prompts

Requested model: `gpt-image-2`. Transport used: Codex built-in authenticated
image generation because this unattended shell did not expose an
`OPENAI_API_KEY` for the bundled CLI. All outputs were visually reviewed before
promotion; prompts below are the final production prompts, lightly wrapped for
readability only.

## Six-card master

```text
Use case: stylized-concept
Asset type: production game asset contact sheet for a premium tablet game for ages 5-6
Primary request: Create exactly SIX separate animal motion cards in a precise 3 columns by 2 rows contact sheet. The six subjects, in this exact reading order, are: cheerful green frog, friendly cinnamon-brown bear cub, playful coral-red crab, energetic soft-gray bunny, delighted black-and-white penguin, graceful pink flamingo. Each card contains exactly one full-body animal, facing slightly toward camera, in a neutral ready-to-move pose with a joyful expressive face and an exceptionally clear silhouette.
Scene/backdrop: each animal sits inside its own large rounded-rectangle cream toy card with a different saturated inset color (lime, sky blue, coral orange, raspberry pink, turquoise, sunny yellow). Surround every card with a thick, perfectly uniform pure magenta #FF00FF gutter; cards must not touch each other or the canvas edge.
Style/medium: cohesive high-end preschool 3D toy illustration; softly molded vinyl mixed with plush felt details; rounded simplified anatomy; tactile seams and subtle material grain; polished but handmade; premium educational app asset; consistent character proportions and camera angle across all six.
Composition/framing: exact 3x2 grid; identical card dimensions; each entire animal including ears, feet, claws, wings and tail fully visible with generous internal padding; no overlaps; no objects crossing card boundaries; orthographic-like front three-quarter view.
Lighting/mood: bright cheerful studio light, soft grounding shadows contained inside each card, warm welcoming mood.
Color palette: sky blue, leaf green, tangerine, coral, turquoise, butter yellow, cream; deep navy accents only in eyes.
Materials/textures: soft matte vinyl, felt, tiny stitched details, subtle paper-card edge.
Constraints: EXACTLY six cards and exactly one animal per card; no text, no letters, no numerals, no symbols, no badges, no icons, no logos, no watermark; pure magenta gutters clearly visible and completely separating every rounded card; preserve full silhouettes and safe crop space.
Avoid: flat vector art, clip art, glossy plastic glare, photoreal animals, extra animals, duplicate animals, scenery, foliage, props, borders touching, cropped extremities, malformed limbs, text-like marks.
```
