# GPT Image 2 production prompts

The source PNGs in this folder were generated with the built-in GPT Image
workflow during the 2026-09-18 production pass. The structured production
prompts, acceptance status, dimensions, and source checksums are recorded in
`recipe-index.json`; runtime derivatives are finalized deterministically and
documented in `ASSETS.md`.

The art direction is canonical **Papercraft**: physical construction paper,
visible fibers, scissor-cut edges, upper-left light, and soft shadows falling
down-right. Functional runtime copy remains HTML and recorded audio.
